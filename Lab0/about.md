GIT - это система контроля версий ПО, используется для сохранения версий ПО, их контроля, позволяет работать в команде над одним кодом/проектом
Централизованная система позволяет сохранять проект только на одном сервере, распределённая же позволяет сохранять изменять и держать все версии локально на нескольких серверах
Репозиторий в Git это хранилище проекта то есть все файлы и изменения.
