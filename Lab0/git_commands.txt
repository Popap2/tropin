git clone копирует существующий удалённый репозиторий на ваш локальный компьютер
git status показывает текущее состояние файлов
git add добавляет изменённые файлы
git commit создает коммит (фиксирует изменения и сохраняет их в истории проекта)
git push отправляет коммиты в другой репозиторий
git init создаёт новый репозиторий в текущей папке
git pull скачивает последние изменения из репозитория и сразу объединяет их с вашей веткой
git branch управление ветками - создание изменения удаления
git checkout переключает на другую ветку
git log — показывает историю всех созданных коммитов в текущей ветке(логи)
